# Research Assistant - UI Designs

This directory contains all UI designs generated with Google Stitch for the Research Assistant application.

## Directory Structure

```
designs/
├── images/        # PNG screenshots for visual reference
├── code/          # HTML/CSS/JS implementation code
└── [original folders retained for reference]
```

## Screen Inventory

| ID | Screen Name | Description | Files |
|----|-------------|-------------|-------|
| 00 | Project Scope Setup | Initial project configuration and problématique definition | `00-project-scope-setup.*` |
| 01 | PDF Upload Dashboard | Upload interface for research documents | `01-pdf-upload-dashboard.*` |
| 02 | PDF Processing Dashboard | Document processing status and queue | `02-pdf-processing-dashboard.*` |
| 03 | Research Workspace | Main workspace with PDF verification | `03-research-workspace.*` |
| 04 | Research Library | Personal document library and manager | `04-research-library.*` |
| 05 | Literature Synthesis | Themes and synthesis dashboard | `05-literature-synthesis.*` |
| 06 | Research Gaps Analysis | Detailed analysis of research gaps | `06-research-gaps-analysis.*` |
| 07 | Export Bibliography | Bibliography configuration and export | `07-export-bibliography.*` |

## File Formats

- **PNG Images** (`images/`): Visual reference screenshots from Stitch
- **HTML Code** (`code/`): Implementation-ready HTML/CSS/JS code
